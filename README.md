# Antarctic_collapse_and_recovery

Antarctic Governance Collapse and Recovery

This repository contains the MATLAB code required to reproduce the main analyses and key figures for the Antarctic governance collapse and recovery study.

The analysis uses Antarctic Treaty Consultative Meeting measure data and Working Paper co-authorship data to construct collaboration networks, simulate consensus dynamics, and compare modelled decision-making outcomes with observed institutional performance.

Repository contents

* ExtractAllMeasureData.m
* ExtractAllNetworkData.m
* CreateTimeseriesForParameterSearch.m
* Figure_1_MeasuresAndNetworks.m
* Figure_2_ModelledObserved.m
* add_network_to_figure.m
* Make_TIFF.m
* slanCM.m

Required data

The following raw data files are required:

* RawData/MeasureCorpus.csv
* RawData/ATCM_IPWP.xlsx
* RawData/Country_joined.xlsx
* RawData/ATCM_roman_numerals.xlsx

The following processed files are generated by the scripts:

* CreatedData/MeasureData.mat
* CreatedData/MeasureData_NoSATCM.mat
* CreatedData/AveragedNetworks_Revisions/
* CreatedData/AveragedNetworks_NoRevisions/
* CreatedData/Timeseries_Revisions/pk_flat_store.mat
* CreatedData/Timeseries_NoRevisions/pk_flat_store.mat

Reproducing Figure 1

Figure 1 is generated from the observed measure data and the Working Paper co-authorship networks.

Run the following MATLAB scripts in order:

ExtractAllMeasureData
ExtractAllNetworkData
Figure_1_MeasuresAndNetworks

This produces:

Figures/Figure1_MeasuresAndNetworks_Revisions.tif

and, where generated:

Figures/Figure1_MeasuresAndNetworks_NoRevisions.tif

Reproducing Figure 2

Figure 2 compares observed ATCM decision-making outcomes with modelled outcomes from the consensus model.

Run the following MATLAB scripts in order:

ExtractAllMeasureData
ExtractAllNetworkData
CreateTimeseriesForParameterSearch
Figure_2_ModelledObserved

This produces:

Figures/Figure2_ModelledObserved.tif

Full reproduction workflow

To regenerate the processed data and reproduce Figures 1 and 2 from the raw data, run:

ExtractAllMeasureData
ExtractAllNetworkData
CreateTimeseriesForParameterSearch
Figure_1_MeasuresAndNetworks
Figure_2_ModelledObserved

Minimal reproduction workflow

If the processed .mat files are already present, Figure 1 can be reproduced by running:

Figure_1_MeasuresAndNetworks

If CreatedData/Timeseries_Revisions/pk_flat_store.mat is already present, Figure 2 can be reproduced by running:

Figure_2_ModelledObserved
